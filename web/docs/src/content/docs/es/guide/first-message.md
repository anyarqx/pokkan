Vamos a crear un anuncio breve. En este paso solo necesitas un navegador.

## Crea el Kit

<img src="/screenshots/pokkan-create-message.webp" alt="Formulario de nuevo Kit con nombre y formatos" width="2560" height="1552" loading="lazy" decoding="async" />

1. Abre [Mensajes](https://pokkan.net/es/kits).
2. Escribe un nombre, como **Aviso semanal**, o deja el campo vacío para usar el nombre sugerido. Este nombre identifica tu trabajo guardado en Pokkan y queda separado del texto enviado a Discord.
3. Elige **Legacy** para empezar con texto, embeds o encuestas.
4. Crea el Kit.

## Edita el mensaje

Pulsa el texto de la vista previa y escribe tu anuncio. Pulsa fuera del texto para terminar. Si te equivocas, usa **Deshacer** debajo de la vista previa.

:::note[Comprueba el resultado]
Tu texto aparece en el editor. Todavía no se ha publicado nada en Discord.
:::

El borrador se guarda en este navegador. No borres los datos del sitio sin guardar o descargar una copia. Para conocer más controles, consulta la [guía del editor](/es/guide/editor/).
