Components V2 permite organizar las partes de un mensaje como un diseño. Es un formato distinto de Legacy, no una capa añadida sobre un embed.

1. [Abre el ejemplo de Components V2](https://pokkan.net/es/kits?example=components-v2). Se convierte en un nuevo borrador editable.
2. Cambia el título y el horario de atención.
3. Selecciona el Container para cambiar o quitar el color de acento.
4. Usa un **+** para añadir una **Section**. Escribe su texto y elige **Botón** o **Miniatura** en el espacio del accesorio.
5. Para abrir una web, elige **Link** en el selector de estilo del botón, edita su texto directamente e introduce la URL completa en Configurar.

<img src="/screenshots/pokkan-section-link.webp" alt="Section con texto y botón de enlace" width="2560" height="2000" loading="lazy" decoding="async" />

Una Section necesita texto y un accesorio. Comprueba que la validación ya no indica que está incompleta. El accesorio ocupa su propio espacio, separado del texto.

Elige Link para abrir una web desde este ejemplo. Los demás estilos esperan que una aplicación responda al clic, algo que el envío actual de Pokkan no proporciona.

Para embeds o encuestas, crea un Kit Legacy. Guarda una copia antes de cambiar el formato de un mensaje existente.
