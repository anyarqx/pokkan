Vas a crear un mensaje, revisar su vista previa y publicarlo en un canal que administras. No necesitas programar.

## Antes de empezar

- [Abre Pokkan](https://pokkan.net/es/kits) en el navegador.
- Para enviar, necesitas permiso para gestionar webhooks del servidor. Si no lo tienes, pide ayuda a quien lo administra.
- Usa un canal de pruebas. El envío publica un mensaje real para los miembros del canal.

Puedes empezar sin iniciar sesión. Pon un nombre al mensaje para encontrarlo después: Pokkan lo conserva como un **Kit**, listo para volver a abrir y editar. Más adelante aprenderás a guardarlo en tu cuenta o descargar una copia.

## Sigue estos pasos

1. [Crea tu primer mensaje](/es/guide/first-message/).
2. [Conoce el editor](/es/guide/editor/), [añade un embed](/es/guide/embed/) y [prueba Components V2](/es/guide/components-v2/).
3. [Crea un webhook](/es/guide/create-webhook/).
4. Abre **Mensajes → Enviar**, elige el Kit, revisa la vista previa y pega la URL del webhook.
5. Envía una vez y comprueba el canal en Discord.
6. Guarda el Kit en tu cuenta o descarga una copia desde **JSON → Pokkan Payload**.
