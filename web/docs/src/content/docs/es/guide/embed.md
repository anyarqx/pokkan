Un embed agrupa información debajo del texto del mensaje. Sirve para dar un título y organizar los detalles de un anuncio. Empieza con un Kit **Legacy**.

1. Escribe una introducción en el texto del mensaje.
2. Usa el **+** debajo del contenido y elige **Embed**.
3. Edita el título y la descripción en la vista previa.
4. Selecciona el embed y abre su control de color. También puedes dejarlo sin color.
5. Abre **Configurar** para el autor, pie, enlace del título y fecha. Para añadir una miniatura o imagen, usa su control en el embed seleccionado e introduce una URL pública. Haz clic en una imagen existente para cambiarla.

<img src="/screenshots/pokkan-embed-complete.webp" alt="Anuncio Legacy con embed y campos" width="2560" height="2254" loading="lazy" decoding="async" />

La introducción aparece encima del embed. Los campos reúnen pares de nombre y valor que pueden colocarse en línea cuando hay espacio. El contenido más largo o una pantalla estrecha puede hacer que ocupen varias líneas.

La URL de imagen debe abrir una imagen accesible. El enlace de una página no siempre sirve. Pokkan todavía no sube archivos desde este control.

Si te equivocas, deshaz el cambio. Para probar otra disposición, crea un Kit con el siguiente formato.
