Components V2 é um formato de mensagem do Discord que permite organizar textos, mídia e controles em uma sequência. Na Pokkan, você monta essa estrutura na própria prévia, inserindo as partes onde devem aparecer.

Use um **Bloco de texto** para escrever, um **Contêiner** para reunir partes relacionadas e uma **Seção** para colocar texto ao lado de um Botão ou Miniatura. Os **Separadores** criam intervalos entre os elementos. Imagens podem usar endereços públicos, enquanto o componente Arquivo depende de um anexo fornecido no envio. A Pokkan ainda não faz upload desses arquivos.

Uma mensagem V2 aceita até 40 componentes, contando os que ficam dentro de outros. O editor mantém espaço para completar estruturas obrigatórias ainda vazias. Perto do limite, um sinal de mais pode desaparecer porque o espaço restante está reservado para o acessório de uma Seção ou o filho de uma Linha de ação.

V2 não combina com o conteúdo comum de Legacy, embeds, enquetes ou figurinhas na mesma mensagem. Se precisar dessas partes, use um Kit Legacy. A [comparação entre os formatos](/pt-br/discord/formats/) ajuda a escolher, e o [catálogo de elementos](/pt-br/discord/components/) mostra o que pode ser inserido em cada lugar.

Para experimentar, siga [Experimente Components V2](/pt-br/guide/components-v2/) ou consulte [Seções](/pt-br/discord/sections/) para colocar texto ao lado de um acessório.

Referência técnica: [componentes do Discord](https://docs.discord.com/developers/components/reference).
