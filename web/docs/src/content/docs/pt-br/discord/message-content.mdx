---
title: Conteúdo Legacy
description: Escreva, remova e recupere o texto comum de uma mensagem Legacy.
---

O conteúdo é o texto comum acima de um embed, uma enquete ou uma Linha de ação. Uma mensagem Legacy tem no máximo um campo de conteúdo. Em Components V2, use [Bloco de texto](/pt-br/discord/text-displays/).

Clique no texto para editar e selecione palavras para abrir a formatação. Se quiser manter apenas o embed, selecione o conteúdo e use **Remover conteúdo da mensagem**. A lixeira remove o campo inteiro da mensagem. Se você quiser apenas reescrever, apague as palavras e continue na área editável vazia.

Para recuperar a área removida, abra **Adicionar elemento** na raiz e escolha **Conteúdo da mensagem**. Ele volta acima dos outros elementos Legacy, sem poder ser posicionado entre dois embeds. Desfazer recupera o texto removido.

O controle Copiar copia o texto, diferentemente de copiar um Kit completo ou baixar JSON. O conteúdo comum usado aqui aceita até 2.000 caracteres, incluindo os marcadores de formatação. Uma mensagem sem esse texto ainda precisa de algum outro elemento enviável, como embed ou enquete.

Consulte [Formatação](/pt-br/discord/formatting/) para títulos, links, código e menções.
