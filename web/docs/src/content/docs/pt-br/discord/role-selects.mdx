O Select de cargo oferece uma escolha entre cargos do servidor em que a mensagem for usada. Atribuir o cargo ou mudar permissões depende da aplicação que recebe a escolha, não do menu sozinho.

Adicione-o em uma Linha de ação vazia. Edite a indicação e abra Configurar para ID personalizado, mínimo, máximo e desativação. Para deixar cargos selecionados inicialmente, informe seus IDs reais e o tipo cargo em **Valores padrão**. Um cargo excluído no Discord pode invalidar esse valor, então revise as seleções iniciais ao adaptar o Kit para outro servidor.
