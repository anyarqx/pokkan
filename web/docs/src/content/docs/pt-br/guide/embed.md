Um embed agrupa informações abaixo do texto da mensagem. É útil para dar um título e organizar detalhes de um anúncio. Comece com um Kit **Legacy**.

1. Escreva uma introdução no texto da mensagem.
2. Use o **+** abaixo do conteúdo e escolha **Embed**.
3. Edite o título e a descrição diretamente na prévia.
4. Selecione o embed e abra o controle de cor para escolher um destaque. Você também pode deixar sem cor.
5. Abra **Configurar** para definir links e URLs de imagens.

![Anúncio Legacy com embed e campos; interface em inglês](/screenshots/pokkan-legacy-editor.webp)

Confira se a introdução aparece acima do embed. Os campos organizam pares de nome e valor. Campos em linha podem ficar lado a lado quando há espaço; no celular, o texto pode ocupar mais linhas.

A URL de imagem deve abrir uma imagem acessível. O endereço de uma página nem sempre serve. A Pokkan ainda não faz upload de arquivos por esse controle.

Se algo sair errado, desfaça a alteração. Para criar um layout diferente, experimente o próximo formato em outro Kit.
