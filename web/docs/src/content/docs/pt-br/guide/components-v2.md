Components V2 permite organizar partes da mensagem em um layout. É um formato diferente de Legacy: não é uma camada extra sobre um embed.

1. [Abra o exemplo de Components V2](https://pokkan.net/pt-BR/kits?example=components-v2). Ele vira um novo rascunho editável.
2. Altere o título e o horário de atendimento.
3. Selecione o Container para mudar ou remover a cor de destaque.
4. Use um **+** para adicionar uma **Section**. Escreva seu texto e escolha **Botão** ou **Miniatura** no espaço do acessório.
5. Para abrir um site, configure o botão como **Link** e preencha o rótulo e a URL completa.

![Section com texto e botão de link; interface em inglês](/screenshots/pokkan-section-button.webp)

A Section precisa de texto e de um acessório. Confira se a validação parou de apontar essa estrutura como incompleta. O acessório ocupa seu próprio espaço, separado dos textos.

Botões comuns precisam de uma aplicação para responder a cliques; o envio atual da Pokkan não fornece isso. Use Link para o exemplo.

Para embeds ou enquetes, crie um Kit Legacy. Guarde uma cópia antes de mudar o formato de uma mensagem existente.
