Em Components V2, você pode distribuir textos, imagens e controles em uma sequência, agrupando partes relacionadas. O formato usa estruturas próprias, por isso não recebe embeds Legacy.

1. [Abra o exemplo de Components V2](https://pokkan.net/pt-BR/kits?example=components-v2). Ele vira um novo rascunho editável.
2. Altere o título e o horário de atendimento.
3. Selecione o Contêiner para mudar ou remover a cor de destaque.
4. Use um **+** para adicionar uma **Seção**. Escreva seu texto e escolha **Botão** ou **Miniatura** no espaço do acessório.
5. Para abrir um site, escolha **Link** no seletor de estilo dos controles do botão, escreva o texto nele e preencha a URL completa em Configurar.

<img src="/screenshots/pokkan-section-link.webp" alt="Seção com texto e botão de link" width="2560" height="2000" loading="lazy" decoding="async" />

A Seção só fica completa quando tem pelo menos um texto e um acessório, que ocupa seu próprio espaço ao lado dos textos. Depois de preenchê-la, confira se a validação deixou de apontar partes ausentes.

Use o estilo Link neste exemplo para abrir um site. Os estilos de ação precisam de uma aplicação que responda aos cliques, algo que o envio direto da Pokkan não oferece.

Para embeds ou enquetes, crie um Kit Legacy. Guarde uma cópia antes de mudar o formato de uma mensagem existente.
