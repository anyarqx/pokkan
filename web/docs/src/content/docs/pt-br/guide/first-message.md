Vamos criar um anúncio curto. Você só precisa do navegador nesta etapa.

## Crie o Kit

![Formulário de novo Kit com nome e opções de formato; interface em inglês](/screenshots/pokkan-new-kit.webp)

1. Abra [Mensagens](https://pokkan.net/pt-BR/kits).
2. Digite um nome, como **Aviso da semana**, ou deixe em branco para usar o nome sugerido. Ele organiza seu trabalho; não aparece na mensagem enviada.
3. Escolha **Legacy** para começar com texto, embeds ou enquetes.
4. Crie o Kit.

## Edite a mensagem

Toque ou clique no texto da prévia e escreva seu anúncio. Clique fora para terminar. Se alterar algo sem querer, use **Desfazer** abaixo da prévia.

:::note[Confira o resultado]
Seu texto aparece no editor. Nada foi publicado no Discord ainda.
:::

O rascunho fica neste navegador. Não limpe os dados do site antes de salvar ou baixar uma cópia. Para conhecer o editor com mais detalhes, veja o [guia do editor](/pt-br/guide/editor/).
