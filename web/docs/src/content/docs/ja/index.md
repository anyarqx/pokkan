---
title: Discordに最初のメッセージを送ろう
description: Pokkanでメッセージを編集し、Webhookを作ってチャンネルに送信する手順。
---

Pokkanでは、プレビューを直接編集してDiscordのメッセージを作れます。ログインやBotのインストールなしで始められます。

**[はじめてのガイドへ →](/ja/guide/start/)**

作成中のメッセージがある場合は、[Pokkanを開く](https://pokkan.net/ja/kits)か、[Webhookの作成手順](/ja/guide/create-webhook/)を確認してください。

最初のメッセージから保存まで、ガイドの8つのステップを日本語で読めます。リファレンスの未翻訳記事には案内を表示し、英語の本文を使用します。スクリーンショットは英語表示ですが、操作する場所は日本語でも同じです。
