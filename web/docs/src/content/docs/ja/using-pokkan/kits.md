イベントのお知らせやコミュニティの紹介、アンケートを、後から編集して使える**Kit**として残せます。見つけやすい名前を付けておくと、**メッセージ**ページからすぐに開けます。このページには作成・読み込み・送信もまとまっています。Kitの名前は整理用なので、Discordの投稿には表示されません。

## 作成前に保存先を選ぶ

自分用のメッセージなら、上部のセレクターで自分のアカウントを選びます。コミュニティで使う場合は、作成前にPokkanをインストール済みのサーバーを選んでください。他のメンバーも同じ一覧からKitを見つけられます。この選択は新しいKitに適用され、すでに作ったKitが移動することはありません。

ログインしなくても、このブラウザーで個人用の下書きを作り、対応するメッセージをWebhookで送信できます。

## 名前を変えて保存する

1. **…**メニューで名前変更を選びます。一覧で選択済みの名前をもう一度クリックするか、エディターのタイトルをクリックしても開けます。
2. 新しい名前を入力し、**Enter**で確定するか、**Escape**でキャンセルします。空欄でなければ、外側をクリックしても確定できます。
3. ログイン中は**保存**して、変更をアカウントまたはサーバーに残します。

キーボードを使う場合は、一覧でKitにフォーカスを移して**F2**を押します。名前には空白を含めて160文字まで使用できます。

## 後から続きを編集する

同じブラウザーでKitを開き直すと、最後に編集した下書きから続けられます。別の端末でも作業したい場合は、Discordでログインして**保存**してください。元のメッセージを残して別の内容を作るなら、**…**メニューの**複製**を使います。

編集を取り消したいときは、**破棄**で保存済みの版に戻せます。一度も保存していないKitでは、下書きが削除されます。後で必要になりそうな内容は、先に**JSON → Pokkan Payload**からダウンロードしておきましょう。ブラウザーのデータを消す前にも、この方法でコピーを残せます。

一覧からKitを取り除くには**削除**を使います。すでにDiscordに送ったメッセージは、そのままチャンネルに残ります。

## サーバーでの権限

確認済みのメンバーはKitを閲覧・作成できます。編集・削除できるのは作成者、サーバー所有者、管理者またはサーバー管理権限を持つメンバーです。他のメンバーには読み取り専用のプレビューが表示され、自分のコピーを作れます。

Kitの直接URLでは、上記のサーバー権限が必要です。作成者または権限を持つ管理者は、別途閲覧・編集を許可する[共有リンクを作成](/ja/using-pokkan/sharing/)することもできます。作成者が退出してもKitはサーバーに残り、管理者が更新できます。

## 保存が競合したら

別の人やタブが新しい版を保存した場合、古い変更で上書きされないよう保存を拒否します。名前の変更を含むローカルの下書きは残ります。

変更を再適用したい場合は、最新版を読み込む前にコピーをダウンロードしてください。再読み込みは保留中の作業を置き換えます。自動マージはありません。
