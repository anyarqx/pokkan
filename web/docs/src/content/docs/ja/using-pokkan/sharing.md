エディターまたはメッセージの**…**メニューから**共有**を開きます。Kitの直接URLでは既存の権限が適用され、個人のメッセージは所有者、サーバーのメッセージはそのメンバーがアクセスできます。他の人にもアクセスを許可するには、別の**アクセスリンク**を作成してください。

## 保存したメッセージを共有する

1. Kitを保存して**共有**を開き、新しいリンクを利用できる人を選びます。
2. 見せるだけなら**閲覧可能**のままにし、保存済みメッセージを変更してもらう場合は**編集可能**を選びます。
3. 有効期限を決めて**アクセスリンクを作成**を押し、新しい項目からアドレスをコピーします。

サーバーのリンクは、最初はログイン済みのメンバーに限定されます。**リンクを知っている全員**を選ぶと、サーバー外の人もログインせずにそのメッセージを開けます。ただし、非公開のチャンネルやロールの一覧は提供されず、サーバーからPokkanが削除されるとリンクは利用できなくなります。

リンクから開くのは保存済みの内容なので、相手に送る前に編集中の変更を保存してください。編集リンクを受け取った人には、Kitの削除やリンクの管理は許可されません。個人の所有者、またはサーバーKitの作成者と権限を持つ管理者が引き続き管理します。

## 権限を変更・取り消す

リンクごとに権限と有効期限を変更でき、**保存**で反映されます。**アクセスを取り消す**を使うと、そのリンクだけが利用できなくなり、Kitや他のリンクは残ります。

作成したリンクの秘密情報は、そのタブに保存されます。別のタブや端末でアドレスが必要な場合は、**リンクを再生成**から**以前のリンクを置き換える**を選んでください。古いアドレスは使えなくなるため、新しいリンクを相手に送り直します。

## ログインせずに共有する

ブラウザーの下書きでは、**共有**から**一時コピーを作成**を選べます。現在のメッセージがサーバー上の独立したコピーになり、標準で24時間利用できます。1時間または7日間も選べますが、元の下書きを後から編集してもコピーには反映されません。

**非公開の管理リンク**は、コピーの編集、共有リンクの管理、削除に使うため、自分で保管してください。相手には選択した閲覧・編集権限だけを渡せます。管理リンクを紛失すると、有効期限までコピーを取り消せなくなることがあります。

アクセスリンクの期限はコピー自体の期限を超えられません。期限切れのコピーには直ちにアクセスできなくなり、メンテナンス時に削除されます。同じネットワークアドレスから作成できるのは1時間に10件までで、Kitの通常のサイズ制限も適用されます。

## 受け取ったメッセージを使う

**自分のメッセージにコピー**を選ぶと、有効期限後も使える個人用の下書きになります。リンクを開いただけでは自分の一覧には追加されません。

編集権限がある場合は、通常のエディターで変更し、**保存**するとサーバー上のメッセージが更新されます。未保存の変更は同じタブで復元でき、個人用の下書きとは別に扱われます。他の人が先に保存すると自分の変更は残るので、再適用したい内容は**JSON → Pokkan Kit**からダウンロードしてから最新版を読み込んでください。

リンクの取り消しは以後の閲覧と保存を止めますが、相手がすでに作ったコピーは削除できません。メンバー限定リンクで再ログインを求められた場合は、そのサーバーに参加しているDiscordアカウントを使ってください。

共有メッセージの未保存の変更は、編集したアカウント、または未ログイン時のゲストにひも付きます。同じブラウザーでも、別のアカウントからは復元できません。

不正利用の報告には、共有メッセージの下にある**連絡・報告**か、サイト下部のサポートアイコンを使ってください。迷惑な投稿を抑えるためフォームにはログインが必要ですが、ログインできない場合はDiscordのサポートも利用できます。報告は公開されず、制限を適用する前に確認します。共有が制限された場合、管理者は理由を確認して再検討を依頼できます。リンクを作り直しても制限は解除されません。
