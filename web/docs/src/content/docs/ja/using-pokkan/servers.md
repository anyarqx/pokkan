上部でサーバーを選ぶと、そのサーバーで繰り返し使えるメッセージの一覧を開けます。Kitの編集中には、アカウントで利用できるサーバーデータからチャンネルやロールを名前で検索することもできます。

## ログインしてサーバーを選ぶ

1. 上部のアカウント操作からDiscordでログインします。プロフィールとサーバー一覧へのアクセスを許可します。
2. アカウントページで、Pokkanを追加できるサーバーを探します。
3. インストール操作を選びます。そのサーバーにアプリを追加できるかはDiscordが確認します。
4. インストールを完了して戻り、状態を更新します。招待URLを開いただけでは完了扱いになりません。
5. 上部のコンパクトなセレクターでインストール済みサーバーを選びます。**＋**からアカウント管理を開けます。

同じセレクターから個人アカウントに戻れます。サーバー連携が加わる前からPokkanを使っていた場合は、Discordからサーバー一覧へのアクセス許可を求められることがありますが、アカウントや既存のKitはそのまま使えます。

![選択できるサーバーとインストールできるサーバーを表示したアカウントページ](/screenshots/pokkan-account-contexts.webp)

## サーバーのKitを作る

サーバーを選んで**メッセージ**を開き、Kitを作成・保存します。他の認証済みメンバーも閲覧できます。直接リンクでは内容を表示する前に権限を確認し、表示中のコンテキストをKitに合わせることがあります。

作成者と管理権限のあるメンバーは編集できます。他のメンバーは閲覧し、自分のKitを作れます。[権限と下書き](/ja/using-pokkan/kits/)も確認してください。

## チャンネルやロールを挿入する

メンション対応の入力欄で、書式バーのサーバー参照を開きます。名前を検索して選ぶと、`<#123456789012345678>`や`<@&123456789012345678>`のような固定の参照が入ります。

自分が閲覧できるチャンネルだけが候補になります。ボットが見えるチャンネルすべてを見られるわけではありません。権限情報が不足すると候補を表示できない場合があります。

固定の参照と`{channel.name}`は別です。サーバー用Kitは既知の`{guild.name}`と`{guild.id}`をプレビューに使えますが、実行時のユーザーやチャンネルは推測しません。Placeholderの例はWebhook送信時に自動置換されません。

## 更新とログアウト

アカウントページでデータの鮮度や取得失敗を確認できます。通常は約15分で更新し、手動更新には60秒の間隔があります。Discordからさらに待機を求められることもあります。権限変更は次の更新まで反映されない場合があります。

サーバーからの退出、認可の失効、Pokkanの削除によってアクセスできなくなることがあります。一時的な障害でKitは削除されません。ログアウトは現在のセッションだけを終了します。同意を取り消すにはDiscordの**認証済みアプリ**を使います。
