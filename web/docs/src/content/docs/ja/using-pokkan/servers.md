上部で自分のアカウントかサーバーを選ぶと、その保存先のメッセージを開けます。一覧にはPokkanを追加済みのサーバーと、あなたが所有者であるか「サーバーの管理」または「管理者」権限を持つサーバーが表示されます。管理できるサーバーでは、Pokkanを追加する前でもKitを保存できます。それ以外のサーバーは、参加しているだけではPokkanで利用できません。

## サーバーを選ぶ

1. 上部のアカウント操作からDiscordでログインし、プロフィールと参加サーバー一覧へのアクセスを許可します。
2. アバターの隣のセレクターで、個人アカウントかサーバーを選びます。
3. **メッセージ**を開くと、その保存先のKitを表示・作成できます。

アバターとセレクターの**＋**から、アカウントページを開けます。既存アカウントでサーバー一覧へのアクセスを追加しても、Kitはそのまま残ります。

チャンネル、ロール、絵文字を取得するには、アカウントページからPokkanをサーバーに追加します。アプリを追加する権限はDiscordが確認します。招待URLを開くだけでは完了しないので、認証後にPokkanへ戻り、インストール状態を更新してください。

## サーバーのKitを使う

サーバーを選んでからKitを作成・保存すると、権限のある他のメンバーも同じ一覧で見つけられます。直接URLでは、内容を読み込む前にアクセスを確認し、表示中の選択をKitの保存先に合わせることがあります。選択を変えても既存Kitの所有先は移動しません。

非公開の一覧にアクセスしてKitを作成・編集・削除できるのは、サーバー所有者と「管理者」または「サーバー管理」権限を持つメンバーです。Pokkanの追加は必須ではありません。共有リンクでは閲覧や編集を個別に許可できます。[Kitと下書き](/ja/using-pokkan/kits/)も確認してください。

## チャンネル・ロール・絵文字を探す

Pokkanを追加したサーバーでは、対応するテキスト欄に`#`を入力するとチャンネル、`@`を入力するとロールを検索できます。名前の一部を入力し、クリック、タップ、Enterで候補を選ぶと、`<#123456789012345678>`や`<@&123456789012345678>`のような固定参照が挿入されます。ユーザーの一覧は取得しません。

候補には、権限を確認したデータに含まれるカテゴリーや、テキスト、ボイス、アナウンス、ステージ、フォーラムなどのチャンネルが表示されます。`@`では`@everyone`と`@here`も選べます。入力しただけで通知が有効になるわけではないため、送信前に[許可するメンション](/ja/using-pokkan/message-settings/)を確認してください。

チャンネル候補は自分の権限で絞り込まれます。ボットが見えるすべてのチャンネルにアクセスできるわけではなく、権限情報が不足する場合は候補が表示されないことがあります。

絵文字ピッカーには、そのサーバーで自分のロールが利用できる絵文字と、設定されている場合はPokkanの絵文字コレクションが表示されます。他のロールだけに制限された絵文字は含まれません。送信先ではDiscord側の権限や利用制限も適用されます。

`{guild.name}`と`{guild.id}`は、プレビューで既知のサーバー情報を表示するPlaceholderです。Webhook送信で自動置換されるわけではないので、投稿前に保存されたテキストを確認してください。

## データの更新とアクセス変更

アカウントページでデータの状態を確認できます。通常は約15分後に更新されますが、チャンネル名が変わった場合などは手動更新も利用できます。手動更新の間隔は60秒で、Discordの制限によって待ち時間が延びることがあります。

名前や権限の変更が次の更新まで反映されないことはありますが、保存済みデータだけでKitの操作が許可されることはありません。サーバーから退出したり認証を失ったりすると、Kitへのアクセスが停止する場合があります。Pokkanを削除するとチャンネル、ロール、絵文字を新たに取得できなくなりますが、Kitの一覧は削除されません。一時的なDiscordの障害でも保存済みKitは残ります。

ログアウトは現在のPokkanセッションだけを終了します。Discordアカウントへのアクセスを取り消す場合は、Discordの**認証済みアプリ**からPokkanの認証を削除してください。
