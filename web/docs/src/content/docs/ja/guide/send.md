Kitと[Webhook URL](/ja/guide/create-webhook/)を用意します。最初はテスト用チャンネルで送信してください。

## Pokkanで送信する

1. エディターの**送信**を選びます。**キット → 送信**からKitを選ぶこともできます。
2. 本文、リンク、画像、メンションを確認します。
3. Webhookの入力欄にURLを貼り付けます。エラーが出た場合は、先に修正します。
4. 送信ボタンを一度だけ押します。

![プレビューと空のWebhook入力欄がある送信画面。英語表示](/screenshots/pokkan-send-message.webp)

## Discordで確認する

Webhookの送信先チャンネルを開き、メッセージが届いたことを確認します。

:::caution[送信するたびに新しい投稿ができます]
もう一度送信すると別のメッセージが作られます。Kitを編集・削除しても、投稿済みのメッセージは変わりません。
:::

送信に成功すると、Webhook URLはアカウントまたはゲストごとに、このブラウザーで最大30日間記憶されます。入力欄を空にすると削除できます。保存・共有するKitには含まれませんが、共用の端末では記憶させないことをおすすめします。

Webサイトを案内する場合はリンクボタンを使います。アプリの処理を呼び出すボタンやファイルのアップロードは、この送信方法ではまだ利用できません。対応していない内容は送信前に表示されます。

Placeholderを使う場合は**JSON → Discord Payload**も確認してください。プレビューには例や既知のサーバー名が表示されることがありますが、Webhookで送られるのは保存された文字列です。チャンネルに表示したい文章にトークンを置き換えましょう。

失敗したらURL、送信先、検証エラーを確認します。処理中に繰り返し送信しないでください。詳しくは[英語のトラブルシューティング](/en/using-pokkan/troubleshooting/)も参照できます。
