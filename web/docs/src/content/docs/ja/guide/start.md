このガイドではメッセージを作り、プレビューを確認して、自分が管理するチャンネルに投稿します。プログラミングは必要ありません。

## 準備するもの

- ブラウザーで[Pokkanを開きます](https://pokkan.net/ja/kits)。
- 送信には、サーバーでWebhookを管理できる権限が必要です。権限がなければ管理者に相談してください。
- テスト用のチャンネルを使いましょう。送信すると、そのチャンネルのメンバーに見える実際のメッセージが投稿されます。

ログインせずに始められます。後から見つけられるようメッセージに名前を付けると、編集を続けられる**Kit**として残ります。このガイドの後半で、アカウントへの保存やコピーのダウンロードも試します。

## 操作の流れ

1. [最初のメッセージを作ります](/ja/guide/first-message/)。
2. [エディターの使い方](/ja/guide/editor/)を確認し、[embed](/ja/guide/embed/)や[Components V2](/ja/guide/components-v2/)を試します。
3. [Webhookを作成します](/ja/guide/create-webhook/)。
4. **メッセージ → 送信**を開き、Kitを選んでプレビューを確認し、Webhook URLを貼り付けます。
5. 一度だけ送信し、Discordのチャンネルで結果を確認します。
6. Kitをアカウントに保存するか、**JSON → Pokkan Payload**からバックアップをダウンロードします。
