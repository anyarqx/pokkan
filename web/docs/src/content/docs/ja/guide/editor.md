表示されているメッセージをその場で編集できます。文章をクリックまたはタップして書き換え、書式を変えたい言葉を選択してください。ツールバーには、その項目でDiscordが対応する書式が表示されるため、メッセージ本文とボタンのラベルでは使える機能が異なります。

![テキスト、画像、リンクボタンを組み合わせた歓迎メッセージの編集画面](/screenshots/pokkan-components-v2-editor.webp)

パーツを追加したい位置の**＋**を使います。グループ内の＋なら、そのグループに追加されます。パーツを選ぶと色や絵文字などの操作ボタンが現れ、残りの項目は**設定**から編集できます。並べ替えられるパーツには、ドラッグ用のハンドルも表示されます。

変更を試したあとは、画面下部の**元に戻す**で以前の状態に戻れます。作業のコピーを残すには**JSON**からダウンロードしてください。**送信**を押すと、このKitを選んだ送信画面が開くので、投稿前に送信先を確認できます。

スマートフォンでは**メッセージ**から一覧を開きます。Kitを選ぶ、Escapeキーを押す、一覧の外をタップする、のいずれかで編集に戻れます。閉じるボタンは**メッセージを作成**の隣にあります。

## ボタンにWebサイトを設定する

1. ボタンを選択し、操作欄のスタイル見本を押します。
2. **リンク**を選び、ボタンの文字を押して「日程を見る」などのラベルを入力します。
3. **設定**を開き、Webサイトの完全なURLを入力します。

![Section内のボタンで開いたスタイルの選択肢](/screenshots/pokkan-button-style.webp)

キーボードではスタイル見本にフォーカスしてEnterを押します。矢印キーで選び、Enterで確定、Escapeで変更せず閉じます。スタイル変更で消えた項目は**元に戻す**で復元できます。

## Embedだけにする・本文を戻す

1. Embedの上の本文をクリックし、Escapeで文字の入力を終えます。
2. 本文の操作欄にあるごみ箱を押します。Embedは残ります。
3. 再び本文を書くには、メッセージの下の**＋**から**メッセージ内容**を選びます。

本文を書き直したいときは、文字を消して空の欄に続けて入力できます。本文の欄自体が不要ならごみ箱を使ってください。削除した内容は**元に戻す**で復元できます。

## 絵文字と検証

ボタンや投票の回答の絵文字は、その要素を選択して絵文字コントロールを開くと変更できます。検索やカテゴリーで選ぶほか、絵文字やIDの入力、選択の解除もできます。

間違えたら「元に戻す」を使います。＋が出ない場合、その位置が上限に達しているか、追加できない種類かもしれません。検証結果で不足している要素を確認してください。
