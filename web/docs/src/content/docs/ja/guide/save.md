保存は編集できる状態を残す操作です。送信はDiscordに投稿する操作で、別々に行います。

1. Kitに分かりやすい名前を付けます。
2. アカウントに保存する場合は、上部のアカウントメニューからDiscordでログインします。
3. 変更を加えて、エディターで**保存**します。
4. メッセージページまたはサイドバーから開き直し、内容を確認します。

ログインしなくても下書きはこのブラウザーに残ります。ただしクラウドのバックアップではありません。サイトデータを消したり、別のブラウザーに移ったりすると利用できなくなる場合があります。

**破棄**は保存済みの版があればその内容に戻します。新しい未保存のKitでは下書きを削除します。大切な作業を破棄する前に、**JSON → Pokkan Payload**でコピーをダウンロードしてください。

Kitの**…**メニューから編集、名前変更、複製、削除ができます。選択済みの名前を再度クリックするか、リンクでF2を押すと名前を変更できます。Enterで確定、Escapeでキャンセルし、保存で変更を残します。右クリックでもメニューが開きます。削除には確認が必要で、Discordの投稿は消えません。

サーバー用Kitは、サーバーを選んでから作成します。一覧や直接URLにアクセスするには、サーバー所有者か、「管理者」または「サーバー管理」権限を持つメンバーである必要があります。セレクターの変更で既存のKitは移動しません。[アカウントとサーバー](/ja/using-pokkan/servers/)も確認してください。

別の人が先に保存した場合は競合を知らせ、下書きを保持します。**コピーを残して最新版を読み込む**で、未保存の作業を別のローカル下書きに残してから保存済みの版を開けます。[Kitと下書き](/ja/using-pokkan/kits/)でコピーの開き方を確認してください。

保存に失敗した場合は、すぐに再読み込みせず、下書きを残してコピーをダウンロードしてください。
