embedは本文の下に情報をまとめるブロックです。お知らせに見出しを付けたり、詳細を整理したりできます。**Legacy**形式のKitで始めます。

1. メッセージ本文に短い紹介文を書きます。
2. 内容の下にある**＋**から**Embed**を選びます。
3. プレビューでタイトルと説明を編集します。
4. embedを選択し、色のコントロールからアクセントを設定します。色を付けない状態にも戻せます。
5. 設定画面では著者、フッター、タイトルのリンク、日時を指定します。画像やサムネイルは、選択したembed上のメディア操作から公開URLを入力して追加します。表示済みの画像をクリックするとURLを変更できます。

<img src="/screenshots/pokkan-embed-complete.webp" alt="embedとフィールドを含むLegacyのお知らせ" width="2560" height="2254" loading="lazy" decoding="async" />

紹介文がembedの上に表示されれば成功です。フィールドは名前と値の組を整理するために使います。インラインのフィールドは幅に余裕があれば横に並びますが、狭い画面では折り返します。

画像URLは、ブラウザーで画像を開けるアドレスにしてください。WebページのURLとは異なる場合があります。この操作でファイルをアップロードすることはできません。

間違えたら変更を元に戻せます。別のレイアウトを試すには、次の形式で新しいKitを作ってみましょう。
