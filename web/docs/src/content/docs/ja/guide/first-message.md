短いお知らせを作ってみましょう。この段階ではブラウザーだけあれば大丈夫です。

## Kitを作成する

<img src="/screenshots/pokkan-create-message.webp" alt="名前と形式を選ぶ新規Kit画面。スクリーンショットは英語表示" width="2560" height="1552" loading="lazy" decoding="async" />

1. [メッセージを開きます](https://pokkan.net/ja/kits)。
2. 「今週のお知らせ」などの名前を入力します。空欄にすると表示中の名前が使われます。名前は作業を整理するためのもので、送信する本文には入りません。
3. テキスト、embed、投票を使える**Legacy**を選びます。
4. Kitを作成します。

## メッセージを編集する

プレビューの文章をクリックまたはタップして、お知らせを書きます。文章の外を押すと編集が終わります。間違えたらプレビュー下部の**元に戻す**を使います。

:::note[結果を確認]
入力した文章がエディターに表示されます。この時点ではDiscordに投稿されません。
:::

下書きはこのブラウザーに保存されます。保存やバックアップをする前にサイトデータを消さないでください。詳しい操作は[エディターガイド](/ja/guide/editor/)で確認できます。
