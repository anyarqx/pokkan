You will build a message, preview it, and post it to a channel you control. No programming is required.

## Before you start

- Use a browser to [open Pokkan](https://pokkan.net/en/kits).
- For sending, use a Discord server where you can manage webhooks. Ask a server administrator if you do not have that permission.
- Choose a quiet test channel. A send creates a real message visible to that channel's members.

You can start without signing in. Give your message a name so you can find it again: Pokkan keeps it as a **Kit**, ready to reopen and edit. Later in the guide, you will save it to your account or download a copy.

## Your first route through Pokkan

1. [Create a message](/en/guide/first-message/).
2. [Learn the editor](/en/guide/editor/).
3. [Add an embed](/en/guide/embed/) or [try Components V2](/en/guide/components-v2/).
4. [Create a webhook](/en/guide/create-webhook/).
5. [Send your message](/en/guide/send/).
6. [Save and reopen a Kit](/en/guide/save/).
