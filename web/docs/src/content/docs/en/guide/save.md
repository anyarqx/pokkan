title: Save and reopen a Kit
description: Understand local drafts, account saves and portable Pokkan Kit backups.

A Kit holds the editable message. Sending is a separate action from saving.

1. Give the Kit a recognizable name.
2. If you want account storage, sign in with Discord using the account control in the topbar.
3. Make a change and choose **Save** in the editor.
4. Open the Messages page or sidebar and select the name to reopen it.

Without signing in, editing still keeps a draft in this browser. A local draft is not a cloud backup. Clearing site data or moving to another browser can make it unavailable.

**Discard** returns to the saved version when one exists. For a new, unsaved Kit it removes the draft. Download **Pokkan Payload** through JSON before discarding work you may want later.

Use the Kit's **…** menu to edit, rename, duplicate or delete it; right click is also a shortcut. Click the selected name again, or use F2 on its link, to rename inline. Enter confirms and Escape cancels; Save persists the renamed draft. Deletion asks for a second confirmation. Deleting a Kit does not delete a Discord message.

To save a server Kit, choose an installed server before creating it. Members can view and create Kits; the creator and server administrators can edit or delete them. Existing Kits do not move when you change the selector. [Account and servers](/en/using-pokkan/servers/) walks through installation and selection.

If another person saved first, Pokkan keeps your draft and reports a conflict. Download a backup before reloading their version if you want to reapply changes. [Kits and drafts](/en/using-pokkan/kits/) explains the distinction.

Confirm saving by reopening the Kit after the success notice. If Save fails, keep the draft and download a backup instead of refreshing immediately.
