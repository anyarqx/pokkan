An embed is a grouped block below a message, useful for an announcement with a heading and a few details. Start with a **Legacy** Kit.

1. Write a short introduction in the message text.
2. Open the insertion point for Legacy content and choose **Embed**.
3. Edit the embed's title and description directly in the preview.
4. Select the embed and use its color control if you want an accent. Clearing the color leaves it unset.
5. Open **Configure** for the author, footer, title link and timestamp. To add a thumbnail or image, use its media control on the selected embed, then enter a public image address. Click an existing image to change it.

<img src="/screenshots/pokkan-embed-complete.webp" alt="Legacy editor with a community workshop announcement and an embed containing when and where fields" width="2560" height="2254" loading="lazy" decoding="async" />

The introduction appears above the embed. Use fields for short pairs of headings and values, choosing inline placement for details that can fit beside each other. Longer content or a narrow screen can make those fields wrap.

An image URL needs to point to an image the browser can load. Pokkan does not upload files here. A webpage URL is often not an image URL.

The [embed reference](/en/discord/embeds/) walks through every field with its settings, and [Embed fields](/en/discord/embed-fields/) covers ordering and inline layout.
