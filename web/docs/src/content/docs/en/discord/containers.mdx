A Container groups V2 content inside one bordered surface. Use it for a complete event notice: a heading, a Section with a thumbnail, a gallery and a row of links can stay together when you move or duplicate the Container.

<div class="message-example" set:html={messages.en["component-workshop"]} />

Add **Container** from a V2 root plus, then use its internal insertion points for Text Displays, Sections, galleries, Files, Separators or Action Rows. Another Container cannot be placed inside it. To select the group rather than a child, click its surrounding edge.

The node controls offer accent color and spoiler. Clearing the color removes the chosen accent. Spoiler hides the group's contents until revealed, rather than deleting them. Configure contains the optional component ID. Deleting the Container removes its children too, while Undo restores the group.
