---
title: Text Displays
description: Write and format V2 text and arrange blocks in a message, Container or Section.
---

A Text Display is the text block used by Components V2. Add one at the message level, inside a Container or in a Section's text list. Unlike Legacy content, a message can have several Text Displays arranged among other elements.

Click its text to write directly in the message. Headings, lists, links, quotes, spoilers and code can be combined in the same block. Use the [formatting reference](/en/discord/formatting/) when choosing syntax. Open **Configure** to set the component's optional ID.

Select the block's edge for drag, Configure, Delete and More actions. Copy, cut, duplicate and paste work with the whole component, while selecting words and copying works with the text. A Section accepts at most three such blocks and needs one to remain structurally complete.

An empty Text Display is unfinished content. Fill it or remove it, checking whether its parent still has the children it needs. [Validation](/en/using-pokkan/validation/) distinguishes an empty field from a missing Section child.
