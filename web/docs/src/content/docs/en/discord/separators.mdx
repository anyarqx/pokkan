A Separator adds vertical breathing room between V2 elements, with an optional horizontal divider. Insert it at message level or inside a Container, not inside a Section's text list or an Action Row.

Select it and open Configure. **Show divider** controls whether the line is visible. **Small** and **Large** choose the spacing, independently of whether there is a line. Turning the divider off keeps a spacing element rather than deleting the component.

A Separator still counts as a component when its line is hidden. Delete it when you do not need the gap. Use the normal drag or More actions controls to move it between compatible siblings.
