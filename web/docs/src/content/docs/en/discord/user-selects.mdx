A User Select asks the reader to choose Discord users. Discord supplies the available entries, so you do not build a manual list of labels as you would for a String Select.

Add it in an empty Action Row, edit its prompt and open Configure for the custom ID, selection counts and disabled state. **Default values** optionally preselect users by their Discord IDs. Keep the entry type as user and use stable numeric IDs, not display names or mention text such as `@Alex`.

The second menu in this example is the User Select. The local preview shows the prompt, not an authenticated live directory of selectable members.

A chosen user is not a triggering user for placeholders and is not automatically mentioned in the message. The application receiving the interaction decides what to do with the selection. Pokkan does not execute that interaction. See [shared settings](/en/discord/select-menus/) for count/default rules.
