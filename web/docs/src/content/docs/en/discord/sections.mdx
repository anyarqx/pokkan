---
title: Sections
description: Place one to three text blocks beside a Button or Thumbnail and configure the accessory.
---

A Section places one to three Text Displays beside one Button or Thumbnail. It suits an event summary with a registration link or a short description with a small image.

Add **Section** at the V2 message or Container level. Write in the initial text item, then choose **Button** or **Thumbnail** in the accessory slot. Use the plus inside the text area for more Text Displays, up to three. A Section needs at least one text item and its accessory before it can be sent.

Select the accessory to edit its own controls. A Button offers style, emoji, disabled state and destination settings. A Thumbnail lets you edit its image address, description and spoiler. **Replace accessory** swaps between the two types. This is a singular slot, so replacement does not add a second accessory.

Deleting the final Text Display leaves an incomplete Section you can finish again. To remove the whole structure, select the Section's outer edge and delete it. Undo recovers removed text or a replaced accessory. See [Buttons](/en/discord/buttons/), [Thumbnails](/en/discord/thumbnails/) and [Text Displays](/en/discord/text-displays/) for their fields.
