---
title: Legacy vs Components V2
description: Choose embeds and polls or a component-based layout without mixing incompatible Discord formats.
sidebar:
  order: 3
---

| Choose Legacy for               | Choose Components V2 for          |
| ------------------------------- | --------------------------------- |
| Ordinary message content        | Text Display components           |
| Embeds                          | Containers and Sections           |
| Polls                           | An ordered visual layout          |
| Familiar announcement structure | Text beside a button or thumbnail |

Both can use Link Buttons in valid locations. They do not share every building block: a V2 message cannot also contain Legacy content, embeds, polls or stickers.

Once Discord accepts a message as V2, that message cannot have the V2 flag removed. Do not expect editing an already-sent message to freely switch between both formats. Pokkan currently sends new messages rather than editing existing Discord posts.

For a beginner announcement, [start with Legacy](/en/guide/first-message/). To explore layouts, [open the V2 example](https://pokkan.net/en/kits?example=components-v2).

Official reference: [Components V2 behavior](https://docs.discord.com/developers/components/reference).
