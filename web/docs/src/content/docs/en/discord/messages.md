A Discord message is one post in a channel. It can include text and, depending on its format, richer parts such as embeds, polls or components.

In Pokkan, start with **Legacy** for a familiar text-and-embed announcement. Choose **Components V2** when you want to arrange text and components into a layout. The preview helps you compose; the final appearance can vary with Discord's client and available width.

A Kit is your editable source. A sent message is a separate object in Discord. Saving a Kit does not send it, and editing a Kit does not update a previous post.

Mentions can notify people. Review mention settings and test with a small audience before sending an announcement widely.
