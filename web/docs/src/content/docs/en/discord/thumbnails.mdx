---
title: Thumbnails
description: Place an image beside a Section's text and set its address, description and spoiler.
---

A Thumbnail is the small image beside a Section's text. It belongs only to the accessory slot, not at the message root or directly inside a Container. To show a larger image, use a [Media Gallery](/en/discord/media-galleries/).

Add a Section, choose **Thumbnail** in its accessory slot and click the image or unavailable-image control to enter a public image URL. The address popover edits that one image. Configure holds a description of up to 1,024 characters, useful for explaining what the picture conveys.

The selected Thumbnail's controls include spoiler, Configure and replacement with a Button. Reveal a spoiler before editing the image if it is hidden. Replacing the accessory changes its type and does not preserve unrelated Button/image properties, but Undo restores the previous accessory.

A Thumbnail with a missing or unreachable address is not an upload. Check that the URL opens the image directly and is reachable without signing in. The [gallery media-address guidance](/en/discord/media-galleries/#media-addresses) also applies here.
