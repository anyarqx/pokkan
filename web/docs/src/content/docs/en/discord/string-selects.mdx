A String Select contains the options you write yourself, such as “Design” and “Programming”. Add it inside an empty Action Row, or choose String Select from Legacy's root menu to create the row automatically.

Select it, write the visible prompt and open Configure. **Add option** creates another choice. Each option has a label shown to the reader, a value sent to the application, an optional description, optional emoji and a default-selection toggle. Label, value and description each allow up to 100 characters. The value is not a website address unless your application deliberately treats it as one.

Use drag or move controls to reorder options, and remove unused entries. A menu supports up to 25 options. Keep minimum/maximum selection counts compatible with the available options and defaults. For one-choice questions, set both counts to one.
